Before you act: what not to assume

  • The code alone doesn't decide the action. Read it with the group code, any remark codes, the claim type and the payer's policy.
    • {% if code.group == "CO" %}
  • CO means the payer holds the provider responsible. Don't move a CO amount to the patient.
    • {% endif %} {% if code.group == "PR" %}
  • PR assigns the amount to the patient, but check protections first: QMB, Medicaid, a missing or invalid ABN or waiver, or contract terms can still stop you billing the patient.
    • {% endif %} {% if code.group == "OA" %}
  • OA isn't automatically patient responsibility. Check what the remark codes and the prior payer's remittance say.
    • {% endif %}
  • Payers sometimes use codes loosely or differently. If the remittance doesn't make sense with the claim and the contract, research and escalate instead of guessing.
  • The causes, call questions and steps above are common patterns, labelled for learning. Payer, plan, state and contract rules decide the real action.
