Using reference entries safely

  • Official wording first. REVEX descriptions are summaries. For a code's exact wording and its start and stop dates, use the official X12 or CMS list.
  • Context decides the action. The same code can need different actions depending on group code, remark codes, claim type, payer policy and the contract.
  • Examples are illustrative. Payer-specific statements in examples are fictional unless a source is linked.
