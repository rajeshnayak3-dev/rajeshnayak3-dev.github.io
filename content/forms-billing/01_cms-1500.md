## What the CMS-1500 is

The **CMS-1500 (02/12 version)** is the standard paper claim form for **professional** services: physicians, non-physician practitioners, therapists, ambulance services, independent labs and DME suppliers. It's printed in red “drop-out” ink so scanners can read the typed data. Older staff still call it the **HCFA** form.

Most claims are sent electronically as the **837P**, but its fields map directly to the CMS-1500 boxes, so billers think in box numbers either way.

## The top section: patient and insured (boxes 1–13)

| Box | Field | Notes |
|---|---|---|
| 1 | Type of insurance | Medicare, Medicaid, TRICARE, CHAMPVA, group health plan, FECA black lung, other |
| 1a | Insured's ID number | Exactly as on the card, including prefix |
| 2 | Patient's name | Last, first, middle initial, exactly as on the card |
| 3 | Patient's birth date and sex | |
| 4 | Insured's name | The subscriber; may differ from the patient |
| 5 | Patient's address | |
| 6 | Patient relationship to insured | Self, spouse, child, other |
| 7 | Insured's address | |
| 9, 9a, 9d | Other insured's name, policy number, plan name | Used for secondary coverage (and Medigap) |
| 10a–c | Is the condition related to employment, auto accident (with state), other accident? | Drives WC, auto and liability rules |
| 10d | Claim codes | Condition codes required by some payers (for example, workers' comp) |
| 11 | Insured's policy group or FECA number | Group number. For Medicare, used for MSP information: “NONE” if no primary insurance |
| 11a–c | Insured's DOB and sex, other claim ID, plan name | |
| 11d | Is there another health benefit plan? | If yes, complete box 9 |
| 12 | Patient's signature (release of information) | “Signature on file” |
| 13 | Insured's signature (assignment of benefits) | “Signature on file” authorizes payment to the provider |

## The middle section: clinical and claim details (boxes 14–23)

| Box | Field | Notes |
|---|---|---|
| 14 | Date of current illness, injury or pregnancy (LMP) | With a qualifier (431 onset, 484 last menstrual period) |
| 15 | Other date | With a qualifier (for example, initial treatment date) |
| 16 | Dates patient unable to work | Mainly workers' comp |
| 17 | Name of referring, ordering or supervising provider | With a qualifier (DN referring, DK ordering, DQ supervising) |
| 17a | Other ID of that provider | A non-NPI identifier with a qualifier, required only by some payers |
| 17b | NPI of that provider | Missing or invalid NPI causes rejections |
| 18 | Hospitalization dates related to current services | For services during an inpatient stay |
| 19 | Additional claim information | Payer-specific: for example, NDC details, unlisted procedure description, attachment notes |
| 20 | Outside lab? and charges | For purchased diagnostic tests |
| 21 | Diagnosis codes, A to L | Up to 12 ICD-10-CM codes, with ICD indicator **0** |
| 22 | Resubmission code and original reference number | **7** replacement, **8** void, with the payer's original claim number |
| 23 | Prior authorization number | Holds one of three numbers, depending on the service: the **prior authorization number**, the **referral number** for HMO/POS plans, or the 10-character **CLIA number** for in-office lab tests (one per claim, so labs with an auth may need separate claims) |

## The service lines (box 24, up to six lines)

| Box | Field | Notes |
|---|---|---|
| 24A | Dates of service, from and to | Same date for single-day services |
| 24B | Place of service | Two-digit POS code (11 office, 21 inpatient, 22 outpatient hospital, 23 ER) |
| 24C | EMG | Emergency indicator, where required |
| 24D | CPT/HCPCS and up to 4 modifiers | |
| 24E | Diagnosis pointer | Letters A to L pointing to box 21 |
| 24F | Charges | Per line |
| 24G | Days or units | |
| 24H | EPSDT / family planning | Medicaid indicators |
| 24I | ID qualifier | For non-NPI IDs in the shaded area |
| 24J | Rendering provider NPI | Who performed the service |

The **shaded upper half** of each line 24 holds supplemental information. Its most common use is the **NDC** for physician-administered drugs (J-codes and other drug HCPCS), written in this order with no spaces or hyphens inside the NDC:

| Part | Example | Notes |
|---|---|---|
| Qualifier | `N4` | Always N4 for an NDC |
| 11-digit NDC | `12345678901` | 5-4-2 format; add leading zeros if the package shows fewer digits (for example 1234-5678-90 becomes 01234567890) |
| Unit qualifier | `ML` | **UN** (unit or each), **ML** (milliliter), **GR** (gram), **F2** (international unit) or **ME** (milligram) |
| Quantity | `2` | The amount of drug given, in that unit |

So the shaded line reads, for example, `N412345678901 ML2`. The HCPCS units in box 24G are counted separately, by the HCPCS code's own descriptor (for example, J1100 is per 1 mg of dexamethasone).

## The bottom section: provider (boxes 25–33)

| Box | Field | Notes |
|---|---|---|
| 25 | Federal tax ID (EIN or SSN) | Must match the billing provider |
| 26 | Patient's account number | The provider's own reference |
| 27 | Accept assignment? | Yes means the payer pays the provider (and, for Medicare, provider accepts the approved amount) |
| 28 | Total charge | |
| 29 | Amount paid | Patient or other payer payments, per payer rules |
| 30 | Reserved for NUCC use | Leave blank. On the old 08/05 form this was “Balance due”, a common interview question |
| 31 | Signature of physician or supplier | |
| 32, 32a | Service facility location and NPI | Where services were provided, if different from box 33 |
| 33, 33a | Billing provider info, phone and NPI | Who gets paid; must be a physical address, not a P.O. box |

## Box-level errors and their effects

| Error | Likely result |
|---|---|
| 1a/2/3 don't match the payer's records | Rejection: subscriber or patient not found |
| Box 4 shows the patient instead of the subscriber | Rejection or CO-31 |
| 10a–c not answered on an injury claim | Pended for accident questionnaire |
| 11 left blank on a Medicare claim | Rejection (Medicare needs “NONE” or MSP info) |
| 17/17b missing for a test or DME | Denial for missing ordering or referring provider |
| 21 diagnosis invalid for the date | CO-146 |
| 22 missing on a corrected claim | Treated as a duplicate (CO-18) |
| 23 missing when auth exists | CO-197 |
| 24B wrong POS | Wrong rate, CO-5 (procedure inconsistent with place of service) or CO-58 (service rendered in an inappropriate place of service) |
| 24D code deleted or not yet valid on the DOS | CO-181 (procedure code invalid on the date of service) |
| 24E pointing to a non-supporting diagnosis | CO-11 or CO-50 |
| 24J missing or not credentialed | CO-B7, CO-185, or rejection |
| 33 address is a P.O. box (837P) | Rejection |

!!! tip "Paper still matters"
    Even if you never touch paper, the box numbers are how payer representatives, trainers and auditors talk. “Check box 24J” is faster than “check the rendering provider NPI field in loop 2310B.”

!!! mistake "Auditor's red flag"
    The rendering provider in 24J and the billing provider in box 33 swapped, or the group NPI used as the rendering provider. It's one of the most common rejection causes for groups.

!!! interview "If an interviewer asks “Which form is used for professional billing?”"
    “The CMS-1500, sent electronically as the 837P. It's used by physicians, other practitioners and suppliers. Key boxes are 1a for the member ID, 21 for diagnoses, 22 for corrected claims, 23 for the authorization number, 24 for service lines with POS, CPT, modifiers, pointers, charges, units and rendering NPI, and 33 for the billing provider.”
